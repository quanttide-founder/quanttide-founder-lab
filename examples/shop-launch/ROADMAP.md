# 开店助手路线图

把开店助手从「算账工具 + 能力边界框架」升级为一条完整的决策链：找料 → 判 AI 能定多少 → 人拍板。用开店这一个真实场景，把实验室三件工具串起来，最终产出可复用的「AI 能力 vs 现实」偏差地图（定义见 [AGENTS.md](AGENTS.md)）。

## 现状

- 能力边界框架：决策环节 × 输入依赖 A/B/C × 证据等级 L0/L1/L2（`AGENTS.md`）
- 算账工具：`src/ledger.py`（CLI，缺 L1 拒绝计算）与 `src/ledger_gui.py`（GUI，估算代填），只算 A 类
- 首例：滁州热锅串串，`data/火锅串串.md`，含 `[锁]/[L0]/[L1]` 三级参数与缺口

## Phase 1 — 找：接入 knowl-searcher

为每个决策环节备料，实验室只引用语料，不复制副本。

- [ ] 确定开店语料的来源与引用方式（记忆或领域仓库，按路径或子模块引用）
- [ ] 为每个环节导出检索查询，从语料捞候选材料
- [ ] 环节与候选材料落 `data/`，供下一步评估

## Phase 2 — 分：升级能力边界框架

把现有的能力边界框架从手填表格升级为可评估的流水。

- [ ] 输入候选材料 → 输出能力分、输入依赖、证据等级
- [ ] 一致性检查自动化（纯 A ≥ 60、含 C ≤ 80、纯 C ≤ 30）
- [ ] 产出能力对照表，落 `data/`

## Phase 3 — 做：接入 task-board

把 AI 定不了的环节交给人工裁决，标注写回。

- [ ] 待人工判决的环节（L0 假设、C 类判断）导出为 Label Studio 评审卡
- [ ] 标注写回，推进证据等级 L0 → L1 → L2

## Phase 4 — 偏差地图：串联产出

- [ ] 汇总各环节「预测值 vs 实测值」，产出跨场景偏差地图
- [ ] 用它标注每个环节在该品类、该城市的可信度，替代单场景的成败判断
