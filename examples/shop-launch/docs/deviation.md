# 偏差地图使用说明

`src/deviation.py` 的用户文档，对应 [TODO.md](../TODO.md) Phase 3。回答一件事：实测数据回填后，怎么汇总成跨场景的「预测值 vs 实测值」，得出每个环节在该品类、该城市的可信度。

偏差地图是 `AGENTS.md` 产出 ②，比单个场景的成败更有复用价值：它回答的不是「这家店开没开成」，而是「AI 在滁州热锅串串上，哪个环节的判断可以少审、哪个必须人工兜底」。

## schema

`data/偏差地图.csv`，一行一个「环节 × 实测」：

| 字段 | 含义 |
|------|------|
| 环节 | 对照表中的决策环节 |
| 品类 / 城市 | 可信度的坐标，跨场景聚合的键 |
| 预测值 / 实测值 | 数值同口径；预测值为 0 时偏差率留空，不算不编 |
| 偏差率 | `(实测 − 预测) / 预测`，`--check` 会核对算术 |
| 证据等级 | 实测行必须 L2 |
| 来源日期 | 实测发生日期 |

## 最短可跑命令

```sh
python3 src/deviation.py            # 汇总
python3 src/deviation.py --check    # 只校验 schema 与偏差率
```

无实测数据时（当前状态）：

```
缺数据：data/偏差地图.csv 尚无实测行。
等探店 4 数据与丰全巷摆摊记录回填（TODO.md 3.3）后再汇总。
```

退出码 `2`——**报缺口，不输出空结论**，与 `ledger.py` 缺 L1 拒绝计算同一策略。

回填 3 行后：

```
── 偏差地图 3 行（证据等级 L2）──
  [定价] 热锅串串/滁州  预测 2.5 → 实测 2.0  偏差 -20.0%
  [财务测算] 热锅串串/滁州  预测 0.10 → 实测 0.13  偏差 +30.0%

── 品类/城市可信度（平均 |偏差|，越低越可信）──
  热锅串串/滁州  3 个环节  平均偏差 20.9%
```

## 结果怎么读

平均 |偏差| 是该品类 / 该城市下的整体可信度：越低说明 AI 预测越贴，该场景可少审；越高越要人工兜底。单环节的偏差率则回答「具体哪个环节可信」——如鲜切牛肉签售价、损耗率 vs 10%、客单价落点这三件实测（见 `docs/AI 辅助开店.md` 第二层验证）。

## 边界

- **只有 L2 行进图**。预测值是 A 类推导，实测值必须来自实地；等级不够的行 `validate` 拒收
- **可信度按品类/城市分组**。跨品类平均没有意义，不给全局分数
- **数据未到位前无结论**。3.3 是 ⏳ 外部依赖（探店 4 数据 + 丰全巷摆摊记录），脚本只等数据，不代填
