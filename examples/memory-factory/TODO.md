### 2. ✅ 矛盾待观察区的数据结构

### 8. 下一轮：方向判据换语义实现

**做什么**：本轮已证纯词法不承担「方向相反」（结论见 `docs/criteria.md` 四）。下一轮做三件：

### 9. `data/segments.json` 过时

**现状**：提交的基线 51 段，现语料能切 87 段。它是「Python 切段 == Rust 原版」的对照基线（本案例从 Rust 版的 knowl-searcher 移植而来），语料一生长前提就破——`tests/test_searcher.py` 里那条 parity 测试因此在真目录里红着，与代码无关。

**做什么**：改成固定夹具语料锁定。**夹具的期望输出必须由 Rust 版一次性跑出来**——否则 parity 从「Python == Rust」降级成「Python == Python 自己的旧快照」，漂移照样发生却不再报警。

**怎么核**：真语料继续生长时 parity 测试仍是绿的，且基线可追溯到 Rust 产出。
