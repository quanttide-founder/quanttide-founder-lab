## 结论

**三栏全对 7/20 = 35.0%，远低于 80% 的目标线——这一轮的判据不可用。** 失分几乎全在「方向」栏：脚本在 20 块里判了 12 块「方向相反」，金标里一块都没有。根因是把「方向相反」交给了词法——锚点附近出现「不/没/非」就翻极性——而**词面极性不等于语义相反**：「**非常**积极」的「非」被当成否定，是最直白的一例。

## 二、结果

### 规则

每块先用 BM25 在 24 条档案条目里取最像的一条（top1）。BM25 是个老式词频打分法：块与条目共有的词越多、这些词越少见，分越高。不理解它也能读下面的数字——**分数高＝词面更像**。

判定走两问：

| 问 | 条件 | 判为 |
|:--|:--|:--|
| 一、有无对应条目 | top1 分 ≥ 6.0，且共享的罕用词组 ≥ 3 个 | 有 / 无（无 → 全新信号）|
| 二、方向（仅在判「有」时问）| 共享锚点在块里全被「不 / 没 / 无 / 非 / 别 / 未」修饰、在条目里全不被修饰 | 相反 / 一致 |

## 三、边界

1. **方向分支整体失效，是最大失分源。** 62 段里判了 48 段「相反」，金标实际 0 段。三个成因：① 否定词表里有「非」，把「非常积极」当否定（09-20 实锤，窗口原文「是非常｜有益的」）；② ±3 字观察窗太宽，锚点附近偶然出现一个「不 / 没」就改判整条极性；③ 词面极性不同 ≠ 语义相反（09-26「数字资产定价」对「不留下资产的活动」）。另外理由文案把「块否定 / 条目肯定」写死了，没反映实际极性方向——实现缺陷，如实记下。
2. **第一问尚可（16/20）。** 4 个错块同向：事件 / 生活观察块被词法挂上条目，共同点是块里出现 3–5 个档案高频的通用词（状态、感觉、方法、今天），两个阈值拦不住。
3. **条目栏失分来自「分数高 ≠ 首选」。** 09-27、09-30、10-04#1、10-04#7 四块，金标给的是最贴的那条，BM25 top1 却被另一批通用情绪词带偏（都偏向「信心的底色」「失控与重新掌控」）。纯词法下这是排序问题，不是阈值问题。
4. **本轮把 fiction 与 work 集的段也拿 default 的档案判了**（62 + 21 + 4 = 87 段）。记忆仓库的规矩是「蒸馏只在同一记忆集内闭环」，这三集的日志本不该用 default 的档案判——多出的 25 段不影响金标上的准确率，但让结果文件与「48 段相反」这个数虚高。下一轮收窄到 default 集。
5. **两个阈值是本轮的估计值**（分阈 6.0、共享词组下限 3），没有标定过；4 个错块全是「无 → 有」同一方向，阈值很可能偏松。按预注册纪律，本轮没有动。
6. **金标本身的风险照单记下**：金标由 AI 标、脚本由机器判，有同源风险，建议人工抽检 5 块。本轮 35% 偏低，抬分嫌疑不成立。
