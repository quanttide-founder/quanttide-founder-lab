# 意图

## 一句话

用档案当索引回扫日志，把当时没被整合的碎片捞出来、补回档案。

## 两层操作意图

**直接**：捞碎片。档案是蒸馏产物，蒸馏有损——大量细节在提炼时没被归位。这个程序把它们找回来。

**中层**：闭环。档案更新 → 重跑回扫 → 发现新碎片 → 再更新档案。每跑一轮档案更完整，日志被理解得更充分。这是积累，不是消耗。

## 边界

- **只补不删**：程序不改档案，只产出可确认的整合建议；写入由人裁决。
- **同一记忆集内闭环**：某集的日志只回扫该集的档案（沿用记忆仓库的分集规则），不跨集搬运。
- **不做意义判断**：程序判机械正确性，意义由人判。

## 附带意义

若「蒸馏—回扫—再蒸馏」在自己身上跑通，它是一条可迁移的方法（团队知识管理、需求蒸馏、复盘）。这是副产品，不是验收对象——拿它当验收标准会引入无法证伪的题目。
