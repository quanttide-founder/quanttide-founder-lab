## 发现

### 1. 索引粒度是向量臂的生死线（H1）

同一嵌入器、同一批文件，rag 与 idx 的差距是 hit@5 0.29 对 0.79。q01（「AI 写的内容自己读不下去」）是典型：rag 命中五块全是日记片段——日记闲聊在语义空间里离查询很近；idx 的第一名是 `profile/triggers.md` 的「自己不想看自己写的内容」——与查询几乎同义，只是金标文件是 `insight/ai.md`。切块窗口把不同主题拼进同一段落，主题混合稀释了语义信号；结构单元主题纯净，向量才可比。

词法打分下两臂打平（recall 均 0.92）：BM25 靠精确词直接命中文件，粒度差异被掩盖。附带的方法学观察：切块重叠使同一文件多块上榜，路径级判定对 rag 有利——bm25 的 MRR 0.96 高于 idx 0.89 主要来自这个偏袒。

### 2. 词法在本语料上强于向量

idx 臂 recall 0.92 对 0.63，MRR 0.89 对 0.45。语料只有 131 文件、查询多含精确词，BM25 直接命中；向量臂反而在 q04（林远亭营收焦虑）、q13（云服务与定制项目）这类指向具体小说设定的查询上失手（MRR 0.20 / 0.00）。向量的长尾与同义优势没有在本轮查询集里显现——改写稳定性上向量 0.20 也低于词法 0.36。结论限于本轮查询集，不能外推为「向量无用」。

### 3. 预注册的规则融合未达预期（H2 不支持），但机制清楚

- bm25：recall 0.92 → 0.88，MRR 0.89 → 0.90（近似持平）
- embed：recall 0.63 → 0.30，MRR 0.45 → 0.22（显著退化）

退化机制：`fuse` 把基础分归一到 `[0,1]` 后加固定 0.30 路由亲和。BM25 候选分数分散（0.2–1.0），加成可被基础分差覆盖；余弦候选分数聚集（归一后 0.9–1.0），0.30 加成几乎重写排序。且三问路由对查询措辞敏感——q01 未命中路由词表，默认落 `Journal`，于是全部日记单元被抬进 top-5、金标 insight 被系统性打压（top-5 变成五条日记）。

融合的两处正收益：改写稳定性 0.20 → 0.38（路由对改写不敏感，平滑了语义波动）；结构查询 q09（「哪些定了哪些待定」）召回 0.33 → 0.67（`待定` 命中方向词表，roadmap 单元被正确抬升）。

### 4. 审计坐标（H3）与稳定性（H4）

模型坐标 100% 对 0%：idx 命中给出 `emotion:1-19`、`roadmap:24-28`、章节标题与洞察分级；rag 命中只有 `chunk#2`，无法回答「这属于哪类文档、哪一级信任」。H3 成立，但它是构造保证的——实验的价值在于其余指标证明坐标不是靠牺牲召回换来的（bm25 下 idx 与 rag 持平）。

改写稳定性全臂偏低（0.20–0.38）：语义召回对措辞敏感是共性问题，不是某一臂的缺陷；融合臂在 embed 下最稳定（0.38）。

## 判定汇总

| 假设 | 判定 |
|------|------|
| H1 idx ≥ rag | 部分支持：embed 下强支持（0.79 对 0.29），bm25 下打平 |
| H2 融合提升精度 | 不支持：bm25 近平，embed 显著退化 |
| H3 坐标 100% 对 0% | 支持（构造保证，且未牺牲召回） |
| H4 融合提升稳定性 | 部分支持：embed 下 0.20 → 0.38，bm25 下 0.36 → 0.33 |

## 结论

1. 「结构当事实层」成立：先解析后索引在向量打分下大幅优于裸切块，同时把审计坐标从 0 抬到 100%——结构不是精度的代价，而是精度的前提
2. 「规则做裁决」需要改形态：绝对值加权与分数分布不匹配，固定亲和在窄分布打分器上会淹没基础分；方向性信号本身有效（稳定性、结构查询）
3. 「向量管联想」尚未被本轮验证：语料小、查询含精确词，词法占优；联想主张需要无共同词的同义查询集再测
