# 实验设计：结构化索引与纯 RAG 对照

## 背景与命题

工具箱的工程思路是「结构存知识」：目录约定与规则文件承载语义，读取时恢复成带证据坐标的模型单元；纯 RAG 把结构打平成块，靠向量近似找回。分工设想是——结构当事实层，向量管联想，规则做裁决。

拆成两条可测的子命题：

1. **索引粒度**：同一批文件、同一个打分器，「先解析成模型单元再索引」是否不差于「先切块再索引」
2. **规则融合**：语义候选上叠加三问路由与证据分级的确定性重排，是否提升精度与稳定性

## 假设（预注册）

权重在首轮运行前写死于 `src/rule.rs`（`W_ROUTE=0.30`、`W_TIER=0.10`、fiction 中性亲和 `0.20`），不按结果回调参。

| 编号 | 假设 | 首轮判定 |
|------|------|----------|
| H1 | idx 臂 recall@5 ≥ rag 臂（两种打分器下均成立） | 部分支持，见下 |
| H2 | idx-rule 相对 idx 提升 recall@5 或 MRR | 不支持 |
| H3 | idx 臂命中 100% 带模型坐标，rag 臂 0% | 支持（由构造保证） |
| H4 | 改写稳定性：融合臂 ≥ 未融合臂 | 部分支持 |

## 语料

主仓库 `assets/`（memory 三个记忆集 + fiction），语料边界由工具箱仓库模型决定——模型覆盖的层进语料，尚未建模的层（`intention`、`report`）不进，两臂一致。

| 类型 | 文件数 | 来源 |
|------|--------|------|
| chapter | 78 | 小说各阶段章节 |
| journal | 20 | 日志（集根 + 归档层） |
| profile | 10 | 五轴档案 |
| roadmap | 6 | 方向路线图 |
| insight | 5 | 认知层洞察 |
| emotion | 6 | 观察站情绪日记 |
| novel_meta | 6 | 小说根部元文件（大纲/世界观/决策） |
| 合计 | 131 | 切块 499，切单元 406 |

## 三臂 × 两打分器

| 臂 | 索引方式 | 命中携带 |
|----|----------|----------|
| rag | 字符滑窗 400/320 切块 | 路径 + `chunk#序号` |
| idx | 标题行与 `---` 分隔线切单元，超 900 字按段续分 | 路径 + 类型 + 章节标题 + 行区间 + 洞察分级 |
| idx-rule | idx 候选 top-30 上做规则融合（路由亲和 + 分级加权） | 同 idx |

打分器两个实例：BM25（中文一元 + 二元切词）与 `embedding-3`（480 字符截断，OpenAI 兼容端点，经 quanttide-agent 的 `UreqClient` 发请求）。两臂读同一批文件、同参数，唯一差别是索引粒度——把「打分器」与「索引粒度」两个因子分开，结论才能归因。

## 查询与判定

`data/queries.json`：14 条查询（主题联想 5、跨域联想 4、素材联想 3、结构查询 2），其中 4 条附共 5 条同义改写；金标是 `assets/` 相对路径（人工标注，命中 = 路径后缀互含）。

指标：`hit@5`（任一金标进 top-5）、`recall@5`（命中金标数占比）、MRR（首个金标名次倒数）、模型坐标覆盖率（命中带类型/标题/行区间的比例）、改写稳定性（查询与改写 top-5 路径集合的 Jaccard）。

## 运行

```sh
cargo run -- stats                                          # 语料统计
cargo run -- run --scorer bm25 --out data/YYYY-MM-DD-bm25-results.json
cargo run -- run --scorer embed --out data/YYYY-MM-DD-embed-results.json
cargo test                                                  # 纯函数回归
```

确定性要求：同输入必同输出。BM25 曾因 `HashMap` 迭代顺序导致两次运行排序不一致，已改为查询词排序后求和，由 `tests/experiment.rs` 锁死。

## 风险与方法学说明

- 金标在路径级判定：切块重叠使 rag 臂同一文件多块上榜，路径级判定对 rag 臂有利，MRR 对比偏袒 rag
- 金标由人标注、覆盖有限；未命中不等于检索错——例如 q01 向量臂命中的是语义几乎同义的 profile 条目而非金标 insight 文件
- 向量臂 480 字符截断对长文档不利，查询未加前缀模板
- 融合权重是绝对值，与打分器的分数分布不匹配（余弦候选分数聚集，BM25 分散），退化机制见结果日志
